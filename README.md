Hello! this is the GitHub page for my Payday2 mod Bullet Offset, 
Bullet Offset makes it so that bullets actually originate from your gun instead of the camera!

Im not really big on all the license stuff, so i hereby give you permission to do whatever you want with my code.

Here is the mod description from the modworkshop.net page:

Adds bullet offset so that bullets actually come from your gun instead of your face.
Yes, the Payday gang have been spitting bullets at their enemies all this time. (They have been shot enough times to canonically do this)

The bullet offset is dynamic with the weapon viewmodel using actual muzzle position to position bullets.
Forward offset is disabled, since it could cause you to shoot through walls if you are too close.

-Bullets now actually follow weapon lasers!
-Height over bore is a thing now! No more pixel peeking over obstacles.
-Left side peeking is disadvantageous! Unless you've flipped your viewmodel!
-Shooting around corners is possible!

The bullet offset is only really noticeable for around 5ish meters.

I highly recommend Tactical Leaning by Offyerrocker to go with this mod, as they compliment eachother quite well.

I made this because all my other favorite shooter games have this feature and it absolutely ruined my aim without it.

Mod is at a minimal setup loading directly from main.xml instead of a mod.txt, this makes the mod a bit smaller, and also allows you to either put the mod in the mods folder or the mod_overrides folder.
